# EffectiveMobile-1C-Test
# Тестовое задание: Junior 1С-разработчик (Effective Mobile)

В данном репозитории представлено решение тестового задания на позицию Junior 1С-разработчик.

## Структура репозитория
* `ЭМ_ТестовоеЗадание.epf` — готовый файл внешней обработки для запуска в информационной базе.
* `Модуль_Формы.bsl` — исходный код основного модуля обработки для удобного чтения при код-ревью.

## Реализация динамических условий (Дополнительный функционал)
При разработке были строго учтены переменные условия из ТЗ:

1. **Исключение ведомостей (Дата отправки):** Решение отправлено 11 числа (интервал 11-20). В текст серверного запроса встроено условие, исключающее документы «Ведомость», если день их даты является чётным.
2. **Условное оформление (Пол):** Выделение светло-зеленым цветом строк со статусом «Акцептован» реализовано **программно** (на сервере при инициализации формы).
3. **Вывод информации (Длина фамилии):** Длина фамилии составляет 9 символов. Вывод информации об удаленных документах реализован через создание и открытие **произвольной вспомогательной формы**, в которую массив отсортированных номеров передается в качестве параметра.

## Технические особенности
* Сбор данных реализован одним оптимальным запросом с использованием временных таблиц.
* Учтена логика клиент-серверного взаимодействия (запросы и работа с БД строго на сервере, работа с интерфейсом — на клиенте).
* Алгоритм удаления строк из таблицы значений построен с обходом с конца во избежание смещения индексов.
